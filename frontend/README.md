# AI Navigation Frontend

React + Vite frontend for the AI-Based Autonomous Navigation System.

## Features
- Generate grid
- Run A* navigation
- One-click demo run
- Preview returned path
- View rendered backend image

## Setup

```bash
npm install
npm run dev
```

Frontend runs on:
- http://localhost:5173

Backend should run on:
- http://127.0.0.1:8000
